# `00-data/` — data directory

This folder holds the datasets used by the analysis pipeline, split into two
clearly separated layers:

```text
00-data/
├── raw/        primary data: provided inputs, never written by the pipeline
└── processed/  outputs generated by the pipeline (plus processed/_archive/
                for legacy files kept for reference only)
```

**Its contents are intentionally not versioned** (see `.gitignore`:
`00-data/**`), because the files are large and/or subject to a separate data
license (`LICENSE-data`). Only this README is tracked.

To reproduce the analysis you must place the raw inputs under `raw/` with the
file names listed below.

## `processed/_archive/` — legacy processed files (not read/written by active scripts)

`boot_RII.csv`, `boot_RII_qi.csv`, `boot_RII_qf.csv`, `par_extintion.csv`,
`df.microclima.csv`. `boot_RII.csv` used to be exported by the old RII

## Rule of thumb

- If a script **reads** it and no script **writes** it → `raw/`.
- If a script **writes** it → `processed/`.
- Never write into `raw/`.
